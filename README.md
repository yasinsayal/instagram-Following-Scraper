## 👥 Instagram Following vs Instagram Followers

**Instagram Following** and **Instagram Followers** are different datasets.

An **Instagram Follower Scraper** collects accounts that follow a particular Instagram profile.

An **Instagram Following Scraper** collects accounts that a particular Instagram profile follows.

For example:

```text id="p5t7k2"
Instagram Profile
       │
       ├── Followers
       │      ↓
       │  Instagram Follower Scraper
       │
       └── Following
              ↓
       Instagram Following Scraper
```

This distinction is important when selecting an Instagram data extraction tool for your research.
